# دیتابیس (`0014_kids.sql`)

فقط جدول جدید؛ هیچ جدول موجودی تغییر نمی‌کند. بدون ستون تکراری: امتیازها از trialهای ذخیره‌شده قابل بازسازی‌اند.

| جدول | نقش |
|---|---|
| `kids_parent_accounts` | والد (شماره موبایل، hash رمز، hash کد بازیابی) |
| `kids_profiles` | کودک: نام/لقب، سن (+زمان ثبت)، آواتار، hash توکن دستگاه، شمارنده‌ها (XP، ستاره، زمان بازی، تعداد بازی، آخرین بازی، سطح/مرحلهٔ فعلی) |
| `kids_game_sessions` | هر بازی: PK `(child_id, id)` = کلید ایدمپوتنسی؛ trialهای خام، metrics، ستاره، `signals_json`، سطح قبل/بعد |
| `kids_game_progress` | وضعیت adaptive هر (کودک، بازی): سطح، پنجرهٔ عملکرد، بهترین، تعداد بازی |
| `kids_skill_progress` | کش خروجی Growth (امتیاز مشاهده‌شده، روند، تعداد نمونه) برای ۸ مهارت |
| `kids_daily_journeys` | سفر روزانه، یکتا به‌ازای `(child_id, day)` (روز به وقت تهران) |
| `kids_rewards` | مدال‌ها و دنیاهای باز شده |

حذف کودک/والد، همهٔ جدول‌های بالا را پاک می‌کند (`ON DELETE CASCADE` + حذف صریح در batch).
شاخص‌ها: `(parent_id)` و `(child_id, ended_at)`.
