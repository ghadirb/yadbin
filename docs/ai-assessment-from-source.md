# ساخت آزمون از روی کتاب/منبع

آزمون‌های AI این بخش فقط از متن منبعی که معلم انتخاب کرده ساخته می‌شوند، نه از دانش عمومی مدل. نتیجه همیشه یک **پیش‌نویس** است و همان مسیر قبلی لازم است: ویرایش ← آزمایش (Preview) ← بازخورد ← آماده انتشار ← انتشار.

## انتخاب معلم

کتاب/منبع ← فصل ← درس یا بخش ← تنظیمات (عنوان، تعداد، پایه، درس، سختی، زمان، نوع سؤال، توضیحات). انواع سؤال همان انواع فعلی است: چهارگزینه‌ای، درست/نادرست، جای خالی.

درخواست: `POST /api/ai/assessment-draft-from-source`

```json
{ "sourceId": "…", "sectionIds": ["…"], "questionCount": 10, "questionTypes": ["multiple_choice","true_false"], "level": "intermediate", "title": "…", "notes": "…" }
```

به‌جای `sectionIds` می‌توان `chunkRange` (محدودهٔ دستی) یا `wholeSource: true` فرستاد. انتخاب یک فصل شامل همهٔ درس‌های آن است.

## اتصال AI به منبع (Grounding)

```
انتخاب معلم → بخش‌های مرتبط → prompt مبتنی بر منبع → AI → اعتبارسنجی سؤال‌به‌سؤال → پیش‌نویس
```

- فقط بخش‌های انتخاب‌شده فرستاده می‌شوند (حداکثر حدود ۱۰ هزار نویسه). اگر انتخاب بزرگ‌تر باشد، بخش‌ها به‌صورت یکنواخت و به‌ترتیب اصلی نمونه‌گیری می‌شوند. کل کتاب هرگز فرستاده نمی‌شود.
- هر بخش برچسب دارد (`[C1]`, `[C2]`, …) و داخل `<SOURCE_TEXT>` می‌آید. به مدل گفته می‌شود متن را فقط «داده» بداند و دستورهای داخل آن را نادیده بگیرد. نشانگر پایان متن از خود کتاب حذف می‌شود تا کسی نتواند از آن خارج شود.
- مدل موظف است: فقط از متن بپرسد، دانش بیرونی نیاورد، اگر مطلب کافی نیست **کمتر** سؤال بنویسد، سؤال تکراری ننویسد و برای هر سؤال برچسب بخش (`chunk`) و یک جملهٔ شاهد (`evidence`، ۵ تا ۲۵ کلمه، عیناً از همان بخش) بدهد.
- به مدل هیچ اطلاعات دانش‌آموز، کلاس، تلفن یا شناسه‌ای داده نمی‌شود.

## اعتبارسنجی (ضد hallucination)

هر سؤال فقط وقتی ذخیره می‌شود که:

1. به بخشی ارجاع بدهد که واقعاً فرستاده شده (`no_source` در غیر این صورت).
2. جملهٔ شاهدش واقعاً در همان بخش باشد؛ تطبیق نسبت به ی/ي، نیم‌فاصله، ارقام و علائم مقاوم است ولی نسبت به ساختن مطلب نه (`not_in_source`).
3. شکل و گزینه‌های آن معتبر باشد، با همان قواعد ویرایشگر دستی (`invalid`).
4. از نوع‌های درخواست‌شده باشد (`wrong_type`).
5. برای «جای خالی»، پاسخ در متن بخش باشد (`answer_not_in_source`).
6. تکراری نباشد (`duplicate`).

سؤال‌های نامعتبر حذف می‌شوند (بازسازی حدسی نمی‌شود). پاسخ شامل `droppedQuestions`، `dropReasons` و `shortfall` است. اگر هیچ سؤال معتبری نماند، **هیچ چیز ذخیره نمی‌شود** و خطای قابل تلاش‌مجدد (`retryable: true`) برمی‌گردد.

## محتوای ناکافی

حدود ۳۰۰ نویسهٔ منبع برای هر سؤال مستقل لازم است. اگر معلم بیش از ظرفیت بخواهد، AI صدا زده نمی‌شود و این پاسخ (۴۲۲، `insufficient_content`) می‌آید:

«محتوای انتخاب‌شده برای تولید ۵۰ سؤال مستقل کافی نیست. تعداد پیشنهادی: ۱۲ سؤال.»

معلم می‌تواند تعداد را کم کند، بخش‌های بیشتری انتخاب کند یا فصل کامل را بردارد. متن کمتر از ۲۰۰ نویسه: `content_too_short`. حداکثر ۲۰ سؤال در هر درخواست.

## منبع هر سؤال (Source Reference)

برای هر سؤال `source_id`، `section_id`، `chunk_id`، `page_number` و `source_reference` ذخیره می‌شود. متن خوانای «منبع سؤال» (مثلاً «فصل اول، درس ۲، صفحه ۱۴») را **سرور** از عنوان‌های ذخیره‌شده و شمارهٔ صفحهٔ واقعی می‌سازد، نه از خروجی مدل. اگر بخش واقعی پیدا نشود، مرجع ساخته نمی‌شود (چیزی جعل نمی‌شود). مرجع:

- در ویرایشگر معلم و در نتیجهٔ Preview معلم دیده می‌شود،
- با کپی/نسخهٔ جدید آزمون همراه می‌ماند و با ویرایش متن سؤال حفظ می‌شود،
- در گزارش معلم کنار درصد پاسخ صحیح هر سؤال می‌آید،
- **هرگز** به دانش‌آموز یا صفحهٔ Student Web فرستاده نمی‌شود.

## شکست AI

اگر AI در دسترس نباشد یا خروجی نامعتبر بدهد: ۵۰۳ (`ai_unavailable`) یا ۵۰۲ (`ai_invalid`) با پیام فارسی، بدون آزمون ناقص و بدون مصرف سهمیه. تلاش دوباره بلافاصله ممکن است. fallback مبتنی بر قاعده برای این قابلیت استفاده نمی‌شود چون سؤال مبتنی بر منبع نمی‌سازد؛ ساخت دستی همیشه در دسترس است.

## مصرف و محدودیت

از همان `requireAi` / `consumeAi` و همان شمارندهٔ ماهانهٔ `usage_counters` (feature = `ai`) آزمون AI فعلی استفاده می‌شود. ترتیب: اعتبارسنجی ورودی و مالکیت ← rate limit ← `requireAi` ← `enforceCreate('assessments')` ← AI ← اعتبارسنجی ← ذخیرهٔ پیش‌نویس ← `consumeAi`. یعنی فقط یک پیش‌نویس واقعاً ذخیره‌شده یک واحد مصرف می‌کند و endpoint جدید راهی برای دور زدن سقف نیست. در پلن رایگان که سهمیه تمام شده، پاسخ `FEATURE_LIMIT_REACHED` (۴۰۳) می‌آید.

Rate limit: ۲۰ درخواست در ساعت برای هر معلم؛ و درخواست کاملاً مشابه (دوبار لمس) تا ۲۰ ثانیه رد می‌شود (۴۲۹). درخواست ناموفق این قفل را آزاد می‌کند.

## بعد از ساخت

Preview، انتشار، Student Web، تصحیح و گزارش بدون تغییر همان سیستم آزمون‌های معلم هستند. Preview نتیجه، پیشرفت یا گزارش واقعی ثبت نمی‌کند. نمرهٔ آزمون یک سنجش درسی است و وارد پروفایل شناختی نمی‌شود. در گزارش، رتبه‌بندی دانش‌آموزان وجود ندارد.
