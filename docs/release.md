# انتشار اپ معلم (Myket) — چک‌لیست

## نسخه
- `versionCode`: خودکار = شمارهٔ اجرای workflow `Release APK` (همیشه صعودی؛ لازم برای به‌روزرسانی در مایکت).
- `versionName`: متغیر repo به نام `VERSION_NAME` (یا `-PVERSION_NAME=` محلی)؛ پیش‌فرض `1.0.0`. در صفحهٔ «حساب، پشتیبانی و حریم خصوصی» نمایش داده می‌شود.

## R8 / کوچک‌سازی (خاموش به‌طور پیش‌فرض)
`isMinifyEnabled` فقط با `MINIFY=true` (متغیر repo یا `-PMINIFY=true`) روشن می‌شود و قوانین در `app/proguard-rules.pro` است (مدل‌های JSON، Myket، pdfbox، Tink/security-crypto). تا وقتی روی دستگاه واقعی با **بیلد minify‌شده** این سه مسیر امتحان نشده، روشنش نکنید:
1. ورود/ثبت‌نام (EncryptedSharedPreferences)
2. خواندن PDF کتاب (pdfbox)
3. خرید آزمایشی مایکت

## پیش از ارسال به مایکت
- [ ] `API_BASE_URL` روی Worker واقعی و `MYKET_PUBLIC_KEY` تنظیم است.
- [ ] `/privacy`، `/terms`، `/support` روی همان دامنه باز می‌شوند؛ **متن‌ها را مشاور حقوقی ببیند** (داده‌ی کودکان).
- [ ] لینک روبیکا (`rubika.ir/MaliarProSupport`) و ایتا را دستی باز کنید و درستی‌شان را تأیید کنید.
- [ ] روی دستگاه: «حذف حساب» با رمز غلط (باید پیام خطا بدهد و بیرون نیندازد) و با رمز درست (بازگشت به ورود، ثبت‌نام دوبارهٔ همان شماره ممکن).
- [ ] تصاویر دانش‌آموزان پس از حذف حساب پاک شده‌اند (`files/student_photos` خالی).
- [ ] گزارش خطا: یک بار کرش آزمایشی (debug) → باز کردن اپ → کارت «اپ دفعهٔ قبل ناگهانی بسته شد» → ارسال/پاک کردن.
- [ ] توکن‌هایی که در چت‌ها به اشتراک گذاشته شده‌اند باطل شده‌اند.
